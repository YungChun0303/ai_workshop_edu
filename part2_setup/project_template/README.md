# Project Template

A starter folder for reproducible R research projects that work well with Claude Code. Part of the [AI-Empowered Research workshop](https://github.com/YungChun0303/ai_workshop_edu).

## Quick Start

1. **Copy** this folder and rename it for your project (lowercase, no spaces — e.g., `school_mobility_stl`).
2. **Rename** `project_template.Rproj` to match, then open it in RStudio.
3. **Fill in `CLAUDE.md`** — replace every `[bracketed placeholder]`. This is the most important step.
4. **Put your original data files in `data_raw/`** and never edit them again.
5. **Start Claude Code** in the project folder (`cd` into it, then run `claude`).
6. **Optional: a user-level `CLAUDE.md`.** `claude_global.md` is the workshop instructor's personal file (the Task Clarification Protocol from Part 2). Claude does **not** load it from inside a project. To use it for every project, copy it to `~/.claude/CLAUDE.md` (Windows: `%USERPROFILE%\.claude\CLAUDE.md`), then delete it from your project folder.

## Folder Layout

| Folder | Purpose |
|---|---|
| `data_raw/` | Original data, exactly as received. Read-only. |
| `data_clean/` | Cleaned data, generated by `code/1000`-series scripts. |
| `code/` | `.Rmd` scripts numbered `0000` import → `1000` cleaning → `2000` descriptives → `3000` models. |
| `outputs/figures/`, `outputs/tables/` | Everything the scripts produce. |
| `writing/` | Markdown drafts of Methods, Results, and memos. |

Run scripts in numeric order. Each script reads only from earlier stages.

## Data Safety

- `.gitignore` keeps `data_raw/`, `data_clean/`, and `.Renviron` out of Git. Keep it that way.
- Do not use Claude Code on data containing PHI. See §5 of `CLAUDE.md`.
- Box, OneDrive, and Dropbox folders: mark the project **"Always keep on this device"** so the agent does not read empty placeholder files.
