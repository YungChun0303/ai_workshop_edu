# The Suit Is Not the Scientist

**Yung Chun · published 2026-09-25**

*AI didn't break academic integrity. It broke the instrument we used to infer competence from a page — and more proctoring won't repair it.*

Read it here: **https://yungchun.substack.com/p/the-suit-is-not-the-scientist**

This op-ed is the core reading for Part 4 of the workshop. Its argument in two sentences: if a machine can produce an accurate, novel, well-cited paper, the written artifact no longer certifies the author's understanding. What institutions can still demand is *responsibility*, a person who answers for the claim, made explicit through contribution statements that say plainly what the author did and what the machine did.
